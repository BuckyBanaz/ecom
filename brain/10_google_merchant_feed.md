# 🔗 Google Merchant Center - Merchant API Integration

- **Objective**: Directly integrate with the modern **Google Merchant API** for real-time product synchronization.
- **Plan Location**: `docs/google-merchant-feed-plan.md`
- **Method**: Push updates from our backend to Google whenever a product is created, updated, or deleted.
- **Technology**: Google API Node.js Client (`googleapis`), Service Account authentication.
- **Key Functions**: `insertOrUpdateProduct`, `deleteProduct`.
- **Status**: Plan updated to use modern API.
